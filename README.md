# Aplicaciones PHP

Taller de PHP con programación orientada a objetos.

Aplicaciones:

1. Acrónimo de una frase
2. Fibonacci y factorial
3. Promedio, mediana y moda
4. Operaciones entre conjuntos
5. Decimal a binario
6. Árbol binario a partir de sus recorridos
7. Calculadora con historial

Para correrlo se copia la carpeta en `htdocs` de XAMPP y se abre `http://localhost/aplicaciones-php/`.
